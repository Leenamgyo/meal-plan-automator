# Category Management Settings

## Overview
인벤토리 내 메뉴들을 논리적/시각적으로 분류하기 위한 대분류 카테고리(메인, 샐러드, 사이드 등) 체계를 정의하고 관리하는 환경설정 화면입니다.

## Core Features
- **카테고리 현황 리스트:** 현재 운영 중인 카테고리의 대표 아이콘, 상세 설명, 그리고 해당 카테고리에 속한 '연결된 메뉴 수(Linked Menus)' 표시.
- **대표 색상 (Color Token):** 시스템 전반(플래너, 인벤토리 카드 등)에서 해당 카테고리가 띠게 될 고유 시각적 테마 색상을 지정 및 표시.

## User Interactions
- **새 카테고리 추가:** 상/하단의 `새 카테고리 추가` 버튼을 눌러 신규 분류 체계 작성.
- **편집 및 삭제:** 카테고리 아이템별 우측의 수정(edit) 및 삭제(delete) 아이콘을 눌러 개별 관리.
