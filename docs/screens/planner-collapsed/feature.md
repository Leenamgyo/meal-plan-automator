# Planner Collapsed View

## Overview
큐레이션 패널을 접어두고(collapse), 달력 영역을 최대로 확장하여 거시적인 일정 파악에 집중하는 뷰입니다.

## Core Features
- **확장된 캘린더 뷰:** 화면 전체를 활용하여 각 날짜별 배정된 메뉴를 한눈에 넓게 확인.
- **토글 트리거:** 화면 우측 끝에 큐레이션 패널을 다시 열 수 있는 `chevron_left` 트리거 상시 노출.

## User Interactions
- **패널 열기:** 하단의 `Open Curation Panel` 문구나 우측 트리거를 클릭하여 패널 확장.
- **삭제 인터랙션:** 캘린더에 배정된 메뉴를 더블 클릭하여 즉시 삭제(Delete).
