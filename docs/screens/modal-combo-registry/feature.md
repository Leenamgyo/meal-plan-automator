# Combo Registration Modal

## Overview
인벤토리에 이미 등록된 여러 개의 단품 메뉴들을 묶어 하나의 **콤보(Set) 메뉴**로 등록하는 모달입니다.

## Core Features
- **좌측(선택 패널):** 콤보명과 태그를 입력하고, 검색 바를 통해 개별 단품 메뉴를 찾음.
- **우측(결과 패널):** 콤보에 추가된 단품 항목들의 리스트를 확인하고 개별 항목을 리스트에서 제거 가능.
- **중복 조합 알림:** 동일한 구성의 콤보가 이미 존재할 경우 강력한 경고 메시지(Warning) 하단에 표시.

## User Interactions
- **메뉴 추가(+):** 좌측 리스트에서 단품을 검색 후 `+` 아이콘 클릭 시 우측 패널 리스트로 이동.
- **조합 등록:** 선택을 마친 후 `콤보 등록하기` 버튼을 눌러 인벤토리에 새로운 세트로 저장.
