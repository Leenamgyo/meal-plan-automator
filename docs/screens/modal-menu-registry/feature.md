# Menu Registration Modal (Single Item)

## Overview
기존 자산에 없는 완전히 새로운 단일(Single) 메뉴를 등록하기 위한 상세 폼 모달입니다.

## Core Features
- **아이템 정체성 아이콘:** 메뉴의 시각적 구분을 위한 직관적인 카테고리 아이콘(피자, 면, 케이크 등) 선택.
- **사진 업로드:** 메뉴의 실제 완성된 사진이나 레퍼런스를 첨부할 수 있는 영역.
- **유사 메뉴 알림 (Alert Info):** 입력한 메뉴명과 유사한 기존 자산이 있을 경우 중복 방지 알림.
- **즉시 사용 토글:** 저장과 동시에 오늘의 식단 플래너에 바로 배정하는 편의 기능.

## User Interactions
- **아이콘 선택:** 라디오 버튼 대신 아이콘 클릭 형태의 탭 인터랙션으로 직관성 향상.
- **폼 제출:** `항목 저장` 클릭 시 성공 알림(Alert-OK) 호출.
