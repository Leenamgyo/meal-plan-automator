# Restaurant Profile Settings

## Overview
식당의 공식 명칭, 연락처, 소개 문구 등 외부 및 내부 시스템에서 사용될 기본적인 브랜드 정보를 관리하는 환경설정 화면입니다.

## Core Features
- **브랜드 정보 폼:** 상호명, 전화번호, 소개글 등을 일괄적으로 관리할 수 있는 텍스트 입력 영역.
- **시스템 상태 모니터링:** 로컬 데이터베이스 및 앱 상태(System Ready)와 마지막 업데이트 일시 등을 모니터링하여 표시.
- **유틸리티 기능:** '시스템 매뉴얼' 단축 링크 및 '데이터 백업' 버튼 제공.

## User Interactions
- **변경 사항 저장:** 내용 수정 후 우측 상단의 `변경 사항 저장` 버튼을 통해 로컬 DB(또는 설정 파일)에 즉각 반영.
