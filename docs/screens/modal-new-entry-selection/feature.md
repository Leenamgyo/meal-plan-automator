# New Entry Selection Branch Modal

## Overview
인벤토리 대시보드에서 `+ 새 메뉴 추가`를 눌렀을 때, 사용자가 **단품 메뉴**를 추가할지 **콤보 메뉴**를 추가할지 선택하도록 유도하는 최초 분기 화면입니다.

## Core Features
- **명확한 시각적 분리:** 좌우로 나뉜 카드 UI를 통해 두 가지 선택지를 직관적이고 균형 있게 제시.
- **친절한 설명 문구:** 단품(Create a single standalone dish)과 콤보(Bundle multiple existing items)의 차이를 명확히 기재.

## User Interactions
- **옵션 선택 (Hover & Click):** 각 카드를 호버할 때 카드가 살짝 떠오르고 테마 색상이 입혀지는 시각적 피드백 제공 후, 클릭 시 해당하는 등록 모달(단품/콤보) 뷰로 화면 전환.
