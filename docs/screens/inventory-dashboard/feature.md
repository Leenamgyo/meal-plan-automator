# Inventory Management Dashboard

## Overview
식당의 전체 메뉴와 콤보 자산을 한눈에 파악하고 관리하는 메인 대시보드입니다.

## Core Features
- **자산 통계 (Stats):** 총 인벤토리, 활성 메뉴, 콤보 구성 수량 등 요약 지표 제공.
- **그리드 뷰 최적화:** 대량의 메뉴를 직관적인 카드 형태로 나열. 콤보 전용 라벨링 등 메타 데이터 표시.
- **다중 필터:** 전체, 샐러드, 메인 요리, 사이드, 콤보 전용 등 빠르고 간편한 필터링 버튼.

## User Interactions
- **새 메뉴 추가 카드:** 첫 번째 점선 카드를 클릭하여 신규 등록 프로세스(모달) 시작.
- **빠른 삭제:** 각 카드의 `delete` 아이콘을 클릭하여 항목 제거 전 삭제 경고 모달 호출.
