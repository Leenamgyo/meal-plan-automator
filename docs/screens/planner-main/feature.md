# Planner Main View

## Overview
식당의 한 달 점심 식단을 관리하는 메인 플래너 화면입니다. 달력과 큐레이션 패널이 기본적으로 열려있는 상태입니다.

## Core Features
- **월간 캘린더:** 해당 월의 전체 일정을 한눈에 파악.
- **큐레이션 패널:** 자주 사용하는 메뉴, AI 추천 메뉴 등을 우측 패널에 띄워두고 바로 접근 가능.
- **스마트 어사인 알림:** AI가 추천하는 식단이 준비된 날짜에 힌트 표시.

## User Interactions
- **더블 클릭 (Double-click to Assign):** 큐레이션 패널에 있는 메뉴를 더블 클릭하여 선택된 날짜에 즉시 배정.
- **날짜 클릭:** 달력의 특정 날짜를 클릭하여 활성화.
