# Planner AI Recommendation View

## Overview
메인 플래너의 큐레이션 패널에서 AI 추천 및 검색 필터가 활성화된 상세 뷰입니다.

## Core Features
- **초성/키워드 통합 검색:** 수백 개의 메뉴를 빠르게 필터링.
- **AI 콤보 추천 (AI Combo Box):** 기존 단품들을 조합하여 영양과 맛의 밸런스를 맞춘 세트 메뉴 제안.

## User Interactions
- **AI 콤보 생성 버튼:** `Generate AI Combo` 버튼을 눌러 새로운 식재료나 재고 상황에 맞는 콤보 요청.
- **+ 아이콘 클릭:** 검색된 개별 메뉴나 콤보를 달력의 선택된 날짜에 추가.
