# Success Alert Modal (OK)

## Overview
메뉴 저장, 콤보 생성, 시스템 설정 변경 등 사용자의 주요 액션이 데이터베이스에 문제없이 성공적으로 완료되었음을 명확히 알리는 중앙 팝업 피드백 모달입니다.

## Core Features
- **브랜드 일관성:** 단순한 기본 팝업이 아닌, The Living Kitchen의 `Primary Green (#4CAF50)` 테마 색상과 컴포넌트를 사용한 브랜드 커스텀 UI.
- **배경 블러(Blur) 처리:** 모달이 활성화되어 있을 때 백그라운드 화면(App Container)을 블러 처리하여 시선을 모달의 메시지에 강하게 집중시킴.

## User Interactions
- **Confirm 클릭:** 표시된 텍스트("SUCCESS")를 인지한 뒤 닫기 버튼을 클릭하여 이전 플로우로 자연스럽게 복귀.
